## D-PRECISION-90 — метрика precision (историческая «90%») — ЗАКРЫТО

**«precision ≈90%» была ФИКЦИЕЙ.** В проекте до этапа D НЕ было честной метрики
precision; за неё принимался `masking_correctness C = 90.81%`. Но
masking_correctness B/C считаются ТОЛЬКО по маскам, ЛЁГШИМ НА GOLD
(`measure_lib.mc_check_bc`: маска не на gold → `scored=False` → в знаменатель НЕ
идёт), то есть СТРУКТУРНО СЛЕПЫ к over-маскированию: маска на объявленном
негативе или на неаннотированной прозе в masking C не существует вовсе. На HEAD
этапа B это скрывало **634 ADDRESS-маски на негативах + 2610 ADDRESS-масок на
прозе**. (Второе историческое число — сырой precision **46.3%** — наоборот
ЗАНИЖЕН: считал SUM-на-негативах, банки-cross-type и прозу-on-nothing одним
мешком FP.) **Честная дефиниция (этап D, `measure_lib.precision_by_type`)**:
FP = kept-маска на ОБЪЯВЛЕННОМ негативе, TP = kept-маска на gold СВОЕГО типа,
precision_T = TP/(TP+FP_neg). По ней: ORG 99.77%, PER 99.96%, ADDRESS
66.86% (HEAD b-per) → 99.92% (C). Зеркала — `tests/test_precision_metric.py`.
**Закрыто:** этап D.

## DOG-PASSPORT-GAP — ЗАКРЫТА этапом A1 (2026-08-06)

Найдена этапом DOG (2026-08-05): паспортные данные реального договора
(`C:\shifrator_real\dog.docx`, вне репозитория) уходили открытыми — слово
«паспорт» встречается 34 раза, серия+номер стоит рядом в 30 случаях, детектор

якорь→серия — паттерн допускал `[^\n\d]{0,20}`, реальная формулировка давала

(один пробел), документ ставил между ними `', №'`/`' №'`.

Этап A1 (`entity_types.yaml:132`, тема сессии — только этот паттерн): зазор
`{0,20}` → `{0,40}` (запас сверх измеренного максимума, не безграничный),
разделитель `\s?` → `[ \xa0,]{0,2}№?\.?[ \xa0]{0,2}` (запятая/NBSP/«№» как
опциональные добавки — старое поведение не ломается, каждый элемент
опционален). Старое поведение сохранено байт-в-байт на корпусе v1 (полный
гейт: дельта 0 по всем семи линиям). Результат на целевом
документе: **29 из 30** (было 2), три прогона в одном процессе — sha256
анонимного текста побитно совпал (детерминизм не задет). Оставшийся 1 случай
(зазор >34 символов) сознательно не покрыт — потолок не сделан безграничным.
