# Как завести новый тип — один файл, ~30 минут

Тип заводится **одним файлом**: `tests/corpus_v2/typedefs/<ИМЯ>.yaml`.
Всё остальное (конфиг детектора, место в арбитраже, наборы, корпус, метрика,
авто-тесты) собирается из него. Руками `entity_types.yaml` НЕ правится — его
пишет сборщик.

## Шаги

1. **Скопируйте соседний файл** из `tests/corpus_v2/typedefs/` (ближе всего по
   духу: `REG_ID.yaml` — число под якорем, `REG_NUMBER.yaml` — формульный
   номер, `SHARE_PCT.yaml` — число со словом, `TRANCHE.yaml` — конструкция).

2. **Заполните секцию `detect`** — что ищем:
   - `form:` — класс формы: `digit_run` (прогон цифр: digits, prefix,
     optional_extra) или `raw` (регэксп дословно). Помните: детекция идёт по
     НОРМАЛИЗОВАННОМУ тексту — дефис между цифрами уже схлопнут;
   - `anchor:` / `anti_anchor:` — слово-подтверждение слева / дисквалификатор;
   - `token_prefix:` — как выглядит токен `[ПРЕФИКС_N]`;
   - `rank:` — место в арбитраже (кто побеждает при равной длине спанов);
     занятые ранги перечислит сборщик, если ошибётесь;
   - `sets:` — в какие наборы входит (`personal`, `personal_requisites`,
     `with_money`); «Максимум» получает всё сам;
   - `measure: {leak_class: numeric|text}` — как считать утечку.

3. **Заполните секцию `generator`** — чем проверяем:
   - `provenance:` — откуда формулировки (живые договоры!);
   - `examples:` — не меньше 5 значений; их вплетут в корпус и на них же
     построятся авто-тесты;
   - `negatives:` — не меньше 3 РАЗНЫХ видов случая (`kind`), которые
     маскироваться НЕ должны;
   - `weave:` — обрамление в корпусе: `intro`/`outro` (предложение вокруг
     значения — сюда же слово-якорь, если тип якорный), `neg_intro`.

4. **Соберите и перегенерируйте** (валидатор объяснит, чего не хватает):
   ```bash
   venv/Scripts/python.exe tests/corpus_v2/assemble_types.py
   venv/Scripts/python.exe tests/corpus_v2/generate.py
   venv/Scripts/python.exe tests/corpus_v2/make_manifest.py
   venv/Scripts/python.exe tests/corpus_v2/validate.py
   ```

5. **Проверьте**:
   ```bash
   venv/Scripts/python.exe -m pytest tests/test_typedef_smoke.py tests/test_type_factory.py -q
   venv/Scripts/python.exe tests/corpus/subsample.py
   ```
   Полный `pytest -q` — на приёмке; полный гейт — один раз, последним
   действием этапа. На корпусе v1 новый тип эталона не имеет: рост масок там —
   MASK-SHIFT, разбирается поимённо, планка двигается только владельцем.

## Чего файл НЕ решает

Примеры видит только генератор — детектор читает собранный конфиг без них
(стена, она проверяется тестами). Типы нейросетевого слоя (PERSON/ORG/ADDRESS),
отрицательные классы и правила арбитража фабрика не заводит. В какой набор
входит тип и маскировать ли его вообще — решение владельца, файл его только
записывает.
