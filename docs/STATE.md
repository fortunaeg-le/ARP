## 2. ЧТО ПРОГРАММА ЗАЩИЩАЕТ И НАСКОЛЬКО — сводная картина

**Три оговорки читать ДО чисел, они в силе для всей таблицы.**

1. **Цифры на корпусах — верхняя граница, а не измерение.** Оба корпуса
   ПОРОЖДЕНЫ генератором: конструкция, которую генератор не предусмотрел, не
   появится ни в тексте, ни в разметке, и её отсутствие будет невидимым
   (`E2-CORPUS-POVERTY`). Размеченных реальных договоров нет ни одного.
2. **Реальный документ разметки не имеет вовсе.** По нему считаются только
   КОЛИЧЕСТВА масок и проверка значений глазами. Колонки «полнота» и
   «точность» там пусты не по лени, а потому что сравнивать не с чем.
3. **`CONTRACT_NO` исключён из точности корпуса v1** — не потому, что детектор
   ошибается, а потому, что v1 заморожен с ОБРАТНЫМ определением («номер
   договора — не ПДн»). Цена исключения: 316 расхождений разметки. На корпусе
   v2 тип меряется полностью и без исключений (`V1-SCOPE-CONTRACTNO`).

## 3. Прибор: починен немаскируемый шов (линия «е»)

Символы-разделители сборки PT-1 (`\n` между блоками, `\t` между ячейками) не
принадлежат ни одному сегменту, который читает система, — маску туда поставить
нечем ни при каком качестве детекции. Прибор считал их **недобором**, то есть
утечкой, которой нет. Из-за этого артефакта планка двигалась **дважды**
(журнал `overmask_ledger.json`, записи 2026-08-06 BASE-A6 и 2026-08-09
BASE-LAYOUT — обе называют шов дословно).

Вычитается ТОЛЬКО пересечение двух условий: позиция не принадлежит ни одному
сегменту **И** символ из закрытого набора `\n`/`\t`. Каждое условие поодиночке
было бы дырой (перенос `w:br` внутри абзаца маскируем; нелокализованный сегмент
— это открытый текст), оба заперты стражами `tests/test_seam_boundary.py`.

**Узость доказана сличением дампов, а не объявлена** (`tests/corpus/seam_narrowness.py`,
324 документа, прогон до и после на неизменном `src/`): расхождений вне поля
границ **0**, сущностей с изменившимся перебором **0**, с выросшим недобором
**0**, уменьшений, не объяснённых швом, **0**. Снято 725 символов у 725
сущностей — ровно по одному на сущность.

Результат: недобор **889 → 471** сущностей, **3915 → 3347** символов. Остаток —
уже настоящие короткие маски, долг, а не артефакт. Перебор не двинулся:
`PASSPORT` 428 шт./3441 симв. (`0c-B`), `ADDRESS` 32 шт./303 симв.
