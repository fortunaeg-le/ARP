## 6. Границы, действующие всегда

- Корпус `tests/corpus/**` заморожен — `sha256sum -c MANIFEST.sha256` из `tests/corpus/`
  обязан быть OK до и после любой правки. Корпус не редактировать.
- **Корректность маскировки только растёт.** `masking_correctness` A (round-trip) и B
  (границы) не должны ПАДАТЬ ни на одном этапе — гейт роняется с допуском 0 (условие 5).
  C (тип) — мягкий, печатается, но не роняет. Асимметрия ошибок: пропуск человек поймает на
  проверке, кривую маскировку — нет, поэтому этап, который начнёт маскировать криво ради
  recall, обязан покраснеть.
- Регресс-гейт (`tests/corpus/gate.py`) не должен показывать рост крешей/`leak_v2`/FP или
  смену MANIFEST. Не вешать на pre-commit — CI на PR, трогающем `src/`.
- `~/.shifrator/sessions/` — путь хранилища, имена `key.bin`/`{sid}.enc`/`{sid}.txt`. Смена
  делает существующие сессии невосстановимыми. В тестах — только временный
  `USERPROFILE`/`HOME` (`tmp_path`), никогда реальный `~`.
- Контракт CLI (`python shifrator.py encrypt|decrypt|delete|decrypt-file`), коды возврата,
  `encrypt` печатает в stdout **только** `session_id`.
- Плоские импорты `src/` (не превращать `src/` в пакет).
- Разделитель граничного окна B3: соседние ячейки склеиваются `""`, не `" | "`
  (`src/tokenizer.py`) — иначе «ИНН/телефон через ячейку» снова недетектируем. См.
  [ARCHITECTURE.md](ARCHITECTURE.md), инвариант B3.
- «Пришпиливающие» тесты (`tests/test_wave2_overcapture.py`,
  `tests/component2/test_e_malformed_input.py::...zip_without_any_target_part...`) —
  зелёные = дефект закрыт; не «зеленить» вручную, чинить в коде при поломке.
- **Ключ атомарен, не пересоздаётся на чтении**: `key.bin` создаётся только в
  `save_session` (атомарно, `os.link`/`O_EXCL`); `load_session`/`purge_expired`
  при отсутствии ключа кидают ошибку, а не генерируют новый — тихое
  пересоздание хоронит все прочие сессии директории.
