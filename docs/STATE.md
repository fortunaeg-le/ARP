## 2. Этап A1 — паспорт: было 2 из 30, стало 29 из 30

Целевой документ — `C:\shifrator_real\dog.docx`, **вне репозитория**. Ни одной
его строки нет ни в одном файле репозитория; приборы печатают только числа.

Находка `DOG-PASSPORT-GAP` (этап DOG): серия+номер паспорта стоит рядом со
словом «паспорт» в 30 местах документа, штатный паттерн находил **2**.
Причины: (1) зазор якорь→серия `[^\n\d]{0,20}` против фактических 21-40
символов; (2) разделитель серия→номер `\s?` против фактических `', №'`/`' №'`.

**Правка** (`entity_types.yaml:132`): зазор `{0,20}`→`{0,40}` (запас, не
безграничный), разделитель `\s?`→`[ \xa0,]{0,2}№?\.?[ \xa0]{0,2}` (запятая/
NBSP/«№» опционально, старое поведение не сломано — проверено полным гейтом).

| Что | До | После |
|---|---|---|
| паспортов найдено на `dog.docx` | 2 из 30 | **29 из 30** |
| ложных срабатываний на негативах корпуса v1 | 16 (агрегат) | 16 (без изменений) |
| полный гейт (324 док.) | зелёный | зелёный, дельта 0 |
| детерминизм (3 прогона, 1 процесс) | — | sha256 анонимного текста совпал побитно |
| pytest -q | 1334 passed | 1334 passed (без изменений) |

Оставшийся 1 случай — зазор превышает принятый запас (~34 символа против
потолка 40 c учётом способа счёта); не покрыт сознательно — расширять дальше
означало бы терять якорь как признак (см. ЗАПРЕТ задания).

**Эталон.** Корпус v1 заморожен, не трогался. Корпус v2 (`tests/corpus_v2/`)
получил: `data.passport_parts`/`passport_value` (раздельные серия/номер +
сборка с выбором разделителя), `generate.PASSPORT_STYLES` (7 комбинаций
разделителя и длины зазора), флаг `passport` из `UGLY_POOL` — был заведён на
этапе CORPUS-V2, но не читался НИКЕМ (сам по себе маленькая находка) — теперь
включает выбор стиля. Плюс типизированный негатив «паспорт качества»
(встречается в каждом из 138 документов).

**Находка при замере негатива (не регрессия, см. `FINDINGS.md`
`A1-PASSPORT-QUALITY-FP`):** синтетический «паспорт качества № SS SS NNNNNN»
детектируется как `PASSPORT` во всех 138 случаях. Проверено — тот же образец
ловится и СТАРЫМ (до A1) паттерном байт-в-байт, это пред-существующее
свойство («якорь по слову, без семантики»), не следствие расширения гэпа/
разделителя. Направление ошибки безопасное (лишняя маска, не утечка).

**Разведка (не чинится, `FINDINGS.md` `A1-RIGID-GAP-SURVEY`):** тот же класс
жёсткого гэпа без обоснования измерением — код подразделения паспорта
(`:138`, `{0,10}`), `SNILS` (`:153`, `{0,20}`), `BIRTHDATE` (`:166`, `{0,10}`,
только якорь слева). Не измерено на реальном документе — только чтением кода.
