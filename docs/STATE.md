## 7. Чего НЕ трогать (иначе тихая порча/невосстановимость)

- `~/.shifrator/sessions/` — путь хранилища, имена `key.bin`, `{sid}.enc` (токен-мапа, Fernet),
  `{sid}.txt` (анон-текст). Смена делает существующие сессии невосстановимыми. В тестах —
  только временный `USERPROFILE`/`HOME` (`tmp_path`), НИКОГДА реальный `~`.
- Контракт CLI (`python shifrator.py encrypt|decrypt|delete|decrypt-file`), коды возврата,
  `encrypt` печатает в stdout **только** `session_id`.
- Плоские импорты `src/` (не превращать `src/` в пакет).
- Разделитель граничного окна B3: соседние ячейки склеиваются `""`, не `" | "`
  (`src/tokenizer.py:_boundary_sep`) — иначе «ИНН/телефон через ячейку» снова недетектируем.
  См. [ARCHITECTURE.md](ARCHITECTURE.md), инвариант B3.
