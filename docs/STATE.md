## 4. Что открыто (по приоритету)

Полное описание с id — [`FINDINGS.md`](FINDINGS.md). Кратко:

- **SNILS/BIRTHDATE без детектора** (0c-A) — блокер покрытия, чинится этапом 3.
- **PASSPORT спан-контракт сломан**, recall_exact 0% (0c-B) — не запланирован.
- **ADDRESS: жадный yargy** цепляет голые 6-значные числа не-ПДн как индекс, FP выросли
  этапом 2 (1968→2284) (0c-C/D) — не запланирован.
- **leak_v2-метрика слепа к усечённому топониму** ADDRESS (0c-H) — харнесс занижает утечку.
- **Регистровая дыра** — строчные/заглавные ФИО без нумерации Natasha не ловит; частично
  снято `detection_text`, полностью закрывает этап 2b (второй проход NER по
  регистро-нормализованной копии). Не глобальный `.lower()` — убьёт NER.
- **Непрочитанные зоны `.docx`** (колонтитулы/сноски/надписи/вложенные таблицы) —
  **обнаруживаются**, но не читаются. `encrypt` по умолчанию **отказывается** (`exit 2`,
  fail-closed), обход — `--allow-lossy`/`strict_zones: false` (`entity_types.yaml`), текст
  зон уходит в `{session_id}.unread.json` (**содержит ПДн открытым текстом**, наружу в
  LLM не идёт). На корпусе отказывается 135/324. Научиться читать — этап 6. `w:sdt`
  (content control) — та же дыра, вне корпуса, не покрыт сканером (1-B).
- **B4** — кириллические омоглифы в цифрах реквизита ломают `\d` в НЕ покрытых
  нормализацией случаях, `xfail(strict)` в `tests/test_breaking_leaks.py`.
- **SplitEntities** — разрыв сущности через границу сегмента/ячейки не закрыт (не область
  этапа 2); контракт красный по замыслу.
- `encrypt` принимает только `.docx`/`.txt`; `decrypt-file` — `.docx/.xlsx/.pptx`.
- PDF-извлечение не реализовано. Компонент 1 (веб-интерфейс) не начат.

## 6. Границы, действующие всегда

- Корпус `tests/corpus/**` заморожен — `sha256sum -c MANIFEST.sha256` из `tests/corpus/`
  обязан быть OK до и после любой правки. Корпус не редактировать.
- **Корректность маскировки только растёт.** `masking_correctness` A (round-trip) и B
  (границы) не должны ПАДАТЬ ни на одном этапе — гейт роняется с допуском 0 (условие 5).
  C (тип) — мягкий, печатается, но не роняет. Асимметрия ошибок: пропуск человек поймает на
  проверке, кривую маскировку — нет, поэтому этап, который начнёт маскировать криво ради
  recall, обязан покраснеть.
- Регресс-гейт (`tests/corpus/gate.py`) не должен показывать рост крешей/`leak_v2`/FP или
  смену MANIFEST. Не вешать на pre-commit — CI на PR, трогающем `src/`.
- `~/.shifrator/sessions/` — путь хранилища, имена `key.bin`/`{sid}.enc`/`{sid}.txt`. Смена
  делает существующие сессии невосстановимыми. В тестах — только временный
  `USERPROFILE`/`HOME` (`tmp_path`), никогда реальный `~`.
- Контракт CLI (`python shifrator.py encrypt|decrypt|delete|decrypt-file`), коды возврата,
  `encrypt` печатает в stdout **только** `session_id`.
- Плоские импорты `src/` (не превращать `src/` в пакет).
- Разделитель граничного окна B3: соседние ячейки склеиваются `""`, не `" | "`
  (`src/tokenizer.py`) — иначе «ИНН/телефон через ячейку» снова недетектируем. См.
  [ARCHITECTURE.md](ARCHITECTURE.md), инвариант B3.
- «Пришпиливающие» тесты (`tests/test_wave2_overcapture.py`,
  `tests/component2/test_e_malformed_input.py::...zip_without_any_target_part...`) —
  зелёные = дефект закрыт; не «зеленить» вручную, чинить в коде при поломке.
