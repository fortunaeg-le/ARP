## 4. Якорь через границу ячейки (`DOG-ANCHOR-SPLIT`) — закрыт

Класс зеркальный A6: там разрыв рвал ЗНАЧЕНИЕ, здесь отрывает ЯКОРЬ от
значения («БИК» в одной ячейке строки, число в соседней). Нового механизма нет:
`detect_regex(anchor_prefix=…)` — текст слева, видимый ТОЛЬКО якорю;
`tokenizer._detect_boundary_entities` шаг 3c приклеивает хвост соседней ячейки.
**Граница различается по разметке, не по символу** (пустой `_boundary_sep`, то
есть `table_index`/`row_index`); мягкий перенос и граница абзаца не берутся.
**Направление ошибки — «лучше не найти»:** спан и координаты прежние, анти-якорь
и ограничитель соседних цифр смотрят на ту же склейку и только ужесточают.

**БИК реального договора: 0 → 1. 690 ложных БИК НЕ вернулись** (страж
`test_the_same_number_without_the_anchor_is_not_masked`).

⚠ Попутная находка: замер реального документа шёл по КОРОТКОМУ пути
(`pipeline.run_detection` — только посегментная детекция), где граничных окон
нет вовсе. Переведён на продуктовый `resolve_for_masking`. Отсюда `ORG 69→70`
в §6 — смена пути замера, не движение детекции.
