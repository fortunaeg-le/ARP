### Две правки сторожа по итогам стрельбы

1. **Ложное срабатывание на коммит-сообщении.** Сторож смотрел на всю строку
   команды, включая текст heredoc. Теперь тело heredoc и значение `-m`/`--message`
   из проверки исключаются. Кавычки в целом НЕ вырезаются — иначе
   `bash -c "git push"` прошёл бы.
2. **Обход через кавычки.** Первая версия само-теста поймала, что
   `bash -c "git push"` не блокируется: перед `git` стояла кавычка, не входившая
   в разрешённый класс символов. Кавычки добавлены в класс.
