# Зона корпуса v2 (порождаемого)

Корпус порождается `generate.py`, эталон `gold_v2.json` пишет тот же генератор.
Правки — через `generate.py` и `make_manifest.py`, не руками по файлам.

**Цифры на этом корпусе — верхняя граница, а не измерение:** конструкция, которую
генератор не предусмотрел, не появится ни в тексте, ни в разметке, и её
отсутствие будет невидимым.

**Фабрика типов (TYPE-FACTORY-2).** Новый тип заводится ОДНИМ файлом
`typedefs/<ТИП>.yaml`; `entity_types.yaml` в корне СОБИРАЕТСЯ
(`assemble_types.py` из `entity_types.base.yaml` + typedefs) и руками не
правится. Генератор вплетает примеры/негативы фабричных типов
(`typedef_lib.py`, `generate.factory_block`); авто-тесты — из тех же файлов
(`tests/test_typedef_smoke.py`). Инструкция — `docs/HOWTO_NEW_TYPE.md`.

**`TRANCHE`: запрет детекции снят владельцем 2026-08-08** — черновик составлен
по конкретной документации, условие сторожа исполнено. Именная ветвь
маскируется (`typedefs/TRANCHE.yaml`), порядковая и описательные обороты —
негативы `kind='ordinal-tranche'`. Сторож «TRANCHE с числом = ошибка» в
`validate.py` остаётся.

**Ось искажений распознавания (NOISE-CORPUS).** Отдельный ПРИБОР рядом с
корпусом, а не его правка: классы искажения описаны в `noise/classes/*.yaml`
(что делает распознавание с текстом и ПОЧЕМУ; поле `evidence` отделяет
наблюдённое у пользователя от выведенного), читает их `noise_lib.py`,
порождает пары «чистый/грязный» `generate_noise.py` в `noise/`, считает
разницу `measure_noise.py`. Эталон знает ПРАВИЛЬНОЕ значение (`clean`),
искажается только текст документа. В `gold_v2.json` оси нет ни одним
вхождением — сторож `tests/test_corpus_v2_noise_axis.py`.
Класс описывает распознавание, а НЕ то, что чинит нормализатор: корпус,
собранный под известное лечение, мерил бы лекарство само на себе.

**Стена в обратную сторону:** ничего отсюда не импортируется в `src/` —
[`src/CLAUDE.md`](../../src/CLAUDE.md). С этапа TYPE-FACTORY-2 стена
МЕХАНИЧЕСКАЯ: AST-страж `tests/test_type_factory.py::TestWall` + белый список
сборки + самопроверка «значения генератора не в артефакте».
