Завести новый тип **$1**. Порядок обязателен: тип без эталона невозможно
измерить, а детектор без места в арбитраже молча проигрывает каждое пересечение.

## 1. Сначала эталон, потом детектор

Разметка идёт в корпусе v2 (`tests/corpus_v2/`) — корпус v1 заморожен, нового
типа в нём не появится. Значит:

- добавить тип в реестр `tests/corpus_v2/values.py` с осями (что именно варьируем
  — форма записи, регистр, разрывы) и типизированными негативами;
- перепородить корпус `generate.py`, пересобрать `make_manifest.py`;
- прогнать `validate.py` (он не `test_*.py`, pytest его сам не подберёт).

**Не трогая `src/`.** Пока эталона нет, детектор писать не на чем.

## 2. Объявление типа

`entity_types.yaml`: паттерн/метод, `token_prefix` (без него тип не маскируется и
работает только барьером — так устроены отрицательные классы).

## 3. Место в арбитраже — обязательно

`src/tokenizer.py`: `_REGEX_PRIORITY` (regex-механизм) или `_NER_PRIORITY`
(якорный/ner). Пропуск ловит `assert_priority_contract` — сборка упадёт.
Не «починить» это исключением из контракта: оно там ровно затем, чтобы забытый
тип не проигрывал каждое пересечение молча.

## 4. Наборы типов

`src/type_policy.py`: в какой набор входит тип — `personal`,
`personal_requisites`, `with_money`. `maximum` — сентинел `None`, синхронизировать
не нужно. Решение «в какой набор» — смысловое: спроси владельца, если тип не
очевидно персональный.

## 5. Детектор

`regex_detector.py` (шаблонный слой) либо `anchor_registry.py` (якорная модель:
строгий якорь → реестр → второй проход по падежам). Помни про стену: значения из
`values.py` не читать.

## 6. Измерение и приёмка

- Тесты типа: положительные, негативные и adversarial-формы.
- Замер на корпусе v2: recall и precision по типу.
- `/quick` во время работы, `/gate` — один раз, последним действием.
- Ожидай рост линии «д» в гейте на корпусе v1: эталона нового типа там нет, и
  каждая его маска по построению попадает в «мимо всего». Это MASK-SHIFT, а не
  регресс — но принять его можно только `/promote-baseline` с обоснованием.
