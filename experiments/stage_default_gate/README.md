# stage_default_gate — DEFAULT-GATE (что открыто при настройках по умолчанию)

Этап трогал `src/` (решения владельца 1 и 2), поэтому закончился кругом на
СОБРАННОЙ программе с пересборкой.

| файл | что делает |
|---|---|
| `probe_class.py` | замер класса на корпусе v1: эталон закрыт на МАКСИМУМЕ и открыт при настройках по умолчанию (380 → 6) |
| `probe_class_v2.py` | тот же замер на корпусе v2 (3 из 3483) — ответ «сколько ещё» без половины |
| `probe_inn_case.py` | разбор остатка: у него ДРУГОЙ механизм (ошибка типа, а не вытеснение) |

Порождаемые файлы (`class_probe.json`, `*.log`) в историю не идут —
восстанавливаются запуском на неизменном `src/`. Числа — в записи
[`docs/JOURNAL.md`](../../docs/JOURNAL.md), этап DEFAULT-GATE.
