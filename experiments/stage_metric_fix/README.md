# stage_metric_fix — разведка и доказательства этапа METRIC-FIX

Этап чинил ПРИБОР (измерительный слой), а не систему: `src/` и
`entity_types.yaml` не тронуты ни строкой.

| файл | что делает | живой? |
|---|---|---|
| `probe_header.py` | пробой механизма `AUD1-HEADER-FALSEMISS`: сколько сегментов колонтитулов прибор не локализует | да |
| `calib_fragments.py` | первый заход части 1 — СУММА открытых кусков; показал, почему голая сумма не годится (шум) | да, как доказательство отвергнутого варианта |
| `calib_chain.py` | принятое правило — ВОССТАНОВИМОСТЬ (куски подряд); сетка «пол куска × зазор» по корпусу | да |
| `verify_cases.py` | те же случаи глазами: значение, разорванное переносом, с окрестностью в анонимном тексте | да |
| `narrowness.py` | доказательство узости правки сличением дампов до/после поле за полем | да |
| `recount.py` | пересчёт картины продукта на починенном приборе | да |

Порождаемые файлы (`dump_*.json`, `chain_calib.json`, `frag_calib.json`,
`*.log`) в историю не идут — они восстанавливаются запуском скриптов на
неизменном `src/`, а весят десятки мегабайт. Числа, ради которых они снимались,
записаны в [`docs/JOURNAL.md`](../../docs/JOURNAL.md), запись этапа METRIC-FIX.
